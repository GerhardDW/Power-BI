pg. 36 - Beginning Dax with Power BI
A common technique used in SQL Stored Procedures is to create a series of temporary tables that are refined versions of a previous table. 

You can use variables in DAX in an equivalent way that can make it easier to follow and debug the processing of your data.

The final RETURN statement does not always have to return the most recent variable. It can be useful to output any variable so you can visually inspect the values
contained by that variable. 

This is a form of manual debugging.
